# Baars Glas en Gevelwerken

Website voor Baars Glas en Gevelwerken - specialist in gevelreiniging, glasbewassing, impregneren en buitenreiniging.

## Technologieën

- HTML5
- CSS3 (SCSS)
- JavaScript (jQuery, Bootstrap, Owl Carousel)
- PHP (contactformulier)

## Project structuur

- `index.html` - Hoofdpagina
- `assets/scss/` - SCSS bronbestanden
- `assets/css/` - Gecompileerde CSS
- `assets/js/` - JavaScript bestanden
- `assets/php/` - PHP scripts

## Deployment

Automatische deployment naar FTP server via GitHub Actions bij push naar `main` branch.
